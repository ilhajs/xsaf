## Install

<PackageManagers pkg="@xsaf/tui" />

`@xsaf/tui` requires Node.js 22.19 or newer.

## Start a chat

```ts
import { xsaf } from "@xsaf/agent";
import mockModel from "@xsaf/agent/model/mock";
import tui from "@xsaf/tui";

const agent = xsaf.agent({
  name: "workspace_agent",
  persona: "Be concise.",
  model: mockModel(),
});

await agent.start();

const chat = tui({
  agent,
  sessionId: "terminal",
  async onExit() {
    await agent.stop();
  },
});

chat.start();
```

The configured agent name labels the header and assistant messages. The UI provides a multiline editor, prompt history, Markdown responses, throttled streaming, bounded history, and tool/delegate status updates.

## Add application output

```ts
chat.addMessage("System", "Connected to the workspace.");
chat.setStatus("sync", "Workspace sync", "success");
```

The controller intentionally does not expose Pi TUI internals or automatic tool results. General event telemetry excludes tool arguments and outputs; display sensitive application output only through an explicit `addMessage()` call.

## Shutdown

`stop()` is asynchronous and idempotent. `Ctrl+C` calls it automatically. Put server and agent cleanup in `onExit` so the terminal, listener, and agent close together.
