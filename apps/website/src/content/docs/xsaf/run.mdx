## Signature

```ts
builder.run(prompt: string, sessionId?: string): Promise<InvokeResult>
```

`.run()` is an exact alias of [`.invoke()`](/xsaf/invoke) on `XsafBuilder`.

```ts
const result = await builder.run("Draft a release note", "release-42");
```

The builder must already be started. Session ordering, streaming, memory persistence, tools, and errors behave exactly as they do for `.invoke()`.

`XsafAgent` exposes `.invoke()` directly; it does not add a separate `.run()` alias.
